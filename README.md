# Last Shift

A first-person horror game where players explore an environment, collect essential items, solve simple objectives, and restore power to progress.

## 🎮 Overview

**Last Shift** is a horror game prototype featuring interactive objects, item collection, sliding doors, switches, and a task progression system.

## ✨ Features

- **Interactive Objects:** Interact with objects throughout the environment.
- **Item Collection:** Collect keycards, gasoline, and other items.
- **Locked Doors:** Use a keycard to access restricted areas.
- **Sliding Doors:** Doors open and close with animated movement.
- **Switches and Generators:** Activate objects to progress through the game.
- **Objective System:** Follow in-game objectives to complete tasks.
- **Audio Feedback:** Sound effects accompany interactions and pickups.

## 🎯 Current Objective

1. Find the keycard.
2. Find the gasoline.
3. Start the generator.
4. Continue exploring and progress through the game.

*Objectives may change as development continues.*

## 🖥️ Platform

- **Platform:** Windows PC
- **Engine:** Unity
- **Build Type:** Playtest / Development Build

## 🚀 How to Play

1. Download the Windows build from the repository's Releases page.
2. Extract the downloaded ZIP file.
3. Open the extracted folder.
4. Run the `Last Shift.exe` file.
5. Follow the on-screen objectives and interact with objects to progress.
